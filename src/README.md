# Rust 后端开发圣经

## 第 0—47 章 · mdBook 版

从零基础学习 Rust、HTTP、PostgreSQL、Redis、Kafka、微服务、分布式系统、Docker、CI/CD、Kubernetes 与恢复运维。全书沿同一个 **RustMall** 项目展开。

- 从侧栏选择章节，或使用页面底部的上一章、下一章。
- 点击顶部放大镜搜索；使用主题菜单切换浅色、深色模式。
- 代码框可横向滚动并复制。多文件、第三方依赖和故意编译失败的教学片段，请结合上下文，在对应工程中运行。
- [下载完整项目源码与验证记录](downloads/rustmall-project.zip)。各章使用各自的检查点，最终累积工程位于压缩包的 `rustmall/` 目录。
- [阅读版本与验证说明](edition.md)。

第0—5章从对应PDF按字形坐标、表格网格及代码行号还原；第6—47章使用与PDF一致的校订源稿。去除了纸面页眉页脚和代码显示行号，合并了视觉续行；网页章节编号沿用原书。

本版不改写业务实现。阅读时请按章节区分历史版本、设计示例和最终已实现能力。
